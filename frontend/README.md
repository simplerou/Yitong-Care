# 颐养通前端

按 `web示例/` 原设计迁移为 Vue 3 + TypeScript + Vite，使用 Vue Router Hash 路由与 Pinia 状态管理。原型目录保持不变。

## 本地启动

需要 Node.js 22.12+（或 20.19+）和 npm。

```sh
cd "Yitong Care/frontend"
npm install
npm run dev
```

访问 http://127.0.0.1:5173 。其他命令：`npm run build` 类型检查与构建，`npm run preview` 预览构建产物，`npm test` 演示算法测试。

## 页面

- `#/home` 首页、今日守护与最近对话。
- `#/agent/health`、`med`、`policy`、`diet`、`safety`、`mind` 六个智能体共用组件。
- `#/kb` 文档、`#/chunk` 切块、`#/vector` 入库、`#/search` 检索、`#/records` 检索记录、`#/services` 服务记录。

所有页面使用原型 CSS、SVG 路径、文案和种子数据。键盘焦点、弹窗焦点约束、文件类型及大小校验作为补充。Element Plus 依赖已预留，当前组件使用原设计样式，避免默认主题改变外观。

## 演示边界

- `src/demo/data.ts` 是演示资料，未做医疗或政策时效核验；不可当作正式知识库。
- `src/demo/rag.js` 保留原型 384 维哈希向量与混合召回算法，不是真实 Embedding 或 FAISS。
- 回答由本地片段和模板流式拼装，界面模型名称沿用设计，不调用通义千问。
- TXT / Markdown 读取真实文件；PDF / Word 使用样例正文并提示，真实解析等待后端。
- 文档、问答、检索和反馈只存当前浏览器会话，刷新恢复初始数据；仅长辈模式持久化。
- 工单只作演示，不外呼、不向社区系统提交。当前没有登录和权限隔离。
- 后端、部署文件不在本次改动范围。

## 验证

`npm test` 使用 Node 内置测试运行器和 Vitest：共 9 项测试，检查切块与重叠、向量归一化、高亮转义、智能体知识范围、重新入库、检索快照、问答引用和上传限制。

建议人工检查：六个智能体入口 → 推荐问题 → 回答引用 → 原文翻段；知识库载入示例 → 保存切块 → 向量入库 → 检索 → 检索记录回放；切换长辈模式后刷新确认保留。上传限制为 50MB。

本次已通过 TypeScript 检查、Vite 生产构建及上述 9 项测试。当前执行环境不允许启动本地监听端口，且浏览器连接不可用，尚未进行浏览器截图逐页对比。
