# 颐养通前端

Vue 3 + TypeScript + Vite，使用 Vue Router Hash 路由与 Pinia。界面沿用 `web示例/` 的原设计。

## 本地启动

需要 Node.js 22.12+（或 20.19+）。先启动后端，前端在另一个终端运行：

```sh
cd "Yitong Care/frontend"
npm install
npm run dev
```

访问 http://127.0.0.1:5173 。开发服务器把 `/api` 代理至 http://127.0.0.1:8000 。若后端使用其他地址，修改 `vite.config.ts` 的代理配置，或在本地 `.env` 设置 `VITE_API_BASE` 为完整 API 地址。

## 功能状态

| 页面 | 当前数据来源 |
| --- | --- |
| 知识库管理 `#/kb` | 真实后端：上传、解析、列表、搜索、分页、详情、删除、失败重试 |
| 文本切块 `#/chunk` | 后端预览；点击保存后写入 MySQL，旧向量失效 |
| 首页文档/文本块/向量统计 | 后端数据库统计 |
| 向量入库 `#/vector` | 实际 Embedding 请求、任务进度、FAISS 版本和重建 |
| 向量检索 `#/search` / 检索记录 `#/records` | 后端混合检索、来源原文、持久化历史快照 |
| 六个 Agent 与服务记录 | 浏览器内的独立演示数据，尚未接入真实问答 |

后端不可用时，知识库页面显示错误和重试按钮，不会回退为演示文档。“载入示例”会上传一份明确标记为功能验证用途的 TXT，并真实保存到后端。

保存切块后，在“向量入库”选择文档、核对模型与维度，点击开始，才会调用真实 Embedding。进度和错误来自后端任务，刷新可恢复；失败可继续未完成批次。索引异常时可从数据库重建。Agent 回答仍为演示。

## 使用与验证

1. 后端环境执行 `alembic upgrade head`，确保 `20261028_0003` 已应用。
2. 知识库上传 PDF / DOCX / TXT / Markdown（不超过 50MB），等待解析状态更新。
3. 点击“查看”核对真实正文；点击“切块”调整参数，确认仅预览不修改数据库。
4. 点击“保存切块结果”，刷新页面或回文档详情，确认文本块仍在并能查看原文位置。
5. 在“向量入库”完成任务，再检索该文档内容，查看引用来源和片段字符位置。
6. 刷新检索记录并回放，确认历史结果保留；删除需确认。文档删除或重切块后，实时检索会排除旧片段。

`npm run build` 检查类型并构建；`npm test` 包括演示算法/状态回归以及真实知识库状态测试。

样式保留原型 CSS，适配新增的加载、错误和分页反馈。当前没有登录与角色隔离；转人工、Agent 问答等仍为演示。

检索采用 Embedding + BM25 + RRF；余弦下限只影响语义召回。结果显示原始 RRF/BM25 分数和两路排名，不展示相关概率；旧记录按历史加权分数回放。后端需升级到迁移 0004。

政策顾问页面已调用真实 LangGraph/Qwen 接口，其余 Agent 保留演示。界面支持追问、多轮历史（最多六条）、原文引用、错误重试与清空；当前完整回答返回，政策顾问问答及来源快照由后端持久保存（需迁移0005）。请求等待上限为 600 秒，离开页面会取消前端等待（已开始的后端任务不保证中止）。

政策顾问支持按需联网搜索，前端显示联网配置状态、服务错误及官方网页正文来源；网页引用可打开原始链接，本地引用仍打开原文片段。网页抓取时间和政策发布日期分开显示。

政策顾问显示原文一致性辅助检查的保留段数及政策类别；检查异常或全部拒绝时不展示草稿，原文仍可查看。

政策顾问支持历史会话新建/切换/删除、刷新恢复及分页，点击“查看本次依据”切换对应快照。网页引用打开保存正文，再由单独链接访问官网当前页面。失败或中断问题可显式重试，前端超时先核对服务器状态。浏览器仅记录当前会话ID。
