# 养老政策解读

根据本次咨询目标解释能够核实的政策条款，明确地区、人群、待遇类别和资料缺项。用户提供的条件用于理解咨询，不作为政策事实或资格认证。

本 Skill 由颐养通政策顾问后端固定加载，不是法规数据库，也不自行执行工具。

## 按阶段使用

- 问题理解阶段使用 [咨询理解规则](references/query-analysis.md)，处理范围识别、多轮条件继承与必要追问。
- 回答生成阶段使用 [证据解读规则](references/evidence-answer.md)，处理地区、类别、时效、金额与部分回答。

后端只为当前阶段加载对应参考内容。检索证据、历史记录和确认条件由本次请求提供；流程路由、重试上限、权限、引用及数字校验仍由程序执行。输出遵守后端附加的 JSON 契约。
