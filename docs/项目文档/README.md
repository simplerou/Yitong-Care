## 维护约定

- 目录编号用于排序，不表示功能实现进度；文件名保持原名称，便于搜索。
- `01-项目规划` 是当前需求基线；“规划、待实现、已实现、历史评测”应明确区分。
- 主目录为项目根目录的 `项目文档/`；仓库文档副本为 `Yitong Care/docs/项目文档/`，同名说明文档同步维护。
- 知识源文件保留在主目录的 `data/`，不批量复制 PDF/TXT 进仓库文档副本；副本同步文本清单供阅读。
- 新增文档放入对应分类并更新导航；跨分类引用使用相对链接，避免移动后失效。
